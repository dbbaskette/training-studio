## Icons by their exact ID

Name each icon a design selects exactly. Search the brand's icon library with `search_icons`, one or two plain words, and give the ID it returns as the candidate's `ref`, with `"refType": "library-id"`. The check asks the slides tool whether the brand has that icon, and says so when it does not: search again. An icon named by its ID is the one the person approves and the one every section draws. A picture or a screenshot is still named by what it shows, with no `refType`.
