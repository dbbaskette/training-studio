    What each status means

    approved
    You approved exactly this content, built from exactly these inputs.
    draft
    Not approved in its current form.
    stale
    Something it was built from has changed since.
    not-started
    The file does not exist yet.
    skipped
    You chose to leave its stage out.
    unavailable
    Its stage could not run.
